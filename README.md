# 福建省房屋安全动态监测可视化平台

本项目以福建省房屋安全信息管理系统截至 2024-11-22 的导出数据和《福建省 2024 年度房屋安全白皮书》为基础，建设省—地市—区县多层级数据库与可视化大屏，并通过 2025、2026 年模拟数据验证动态监测能力。

## 当前阶段

- 已归档原始 PDF、Excel 数据源
- 已梳理数据处理、入库、模拟、地图联动和验收 workflow
- 已形成数据库分层设计、可视化页面草案和数据质量清单
- 已生成可复现的 2025/2026 年 ±5% 模拟数据
- 已完成淡蓝色可视化平台首版，入口位于 `apps/web/`
- 已实现福建省地市级地图、区县下钻、年度切换和辅助图表
- 厦门、漳州、泉州下钻优先使用参考平台迁移的高精度区县边界
- 已构建包含 112 个区域、180 个指标和 60,480 条三年度事实记录的完整 SQLite 数据库
- 已形成覆盖筛选器、地图、图表、接口和派生指标的平台数据结构

> Git 仓库只保存代码、配置、文档和可发布的聚合静态数据。原始报告、原始工作簿、GeoPackage、SQLite 数据库、运行日志及本机缓存均保留在本地，不进入公开仓库。

## 建议技术边界

- 地图：福建省地市级边界为默认视图；达到设定缩放级别或点击地市后，自动切换区县边界。
- 数据：原始数据不可覆盖；2024 为基准事实数据；2025/2026 必须带 `is_simulated=true` 标识。
- 监测：时间轴切换年度，地图、指标卡和两侧图表同步联动。
- 上线前：用正式行政区划代码替代名称关联，模拟数据与真实数据物理或逻辑隔离。

## 一键启动

macOS 双击项目根目录的 `start-platform.command`。脚本不会默认占用 3000，而是从 3100 起自动选择可用端口；若平台已经运行，则直接打开现有地址。

Windows 双击项目根目录的 `start-platform.bat`。首次运行会自动安装前端依赖，详细说明见 `docs/windows-development.md`。
