# 房屋安全可视化平台数据结构

本文档以 `database/housing-safety.sqlite` 中的 112 个区域、180 个指标和 60,480 条事实记录为准，用于指导后续页面、筛选器、地图、图表和接口开发。

## 1. 总体模型

平台采用“维度 + 指标事实 + 派生指标”的结构：

```text
时间/场景 ─┐
行政区域 ──┼─> 区域年度指标事实 <─ 指标字典/分类树
房屋属性 ──┤              │
场所类型 ──┤              ├─> 地图、指标卡、排名、趋势
隐患等级 ──┤              └─> 比率、同比、告警、综合分析
整治状态 ──┘
```

事实粒度统一为：

```text
区域 × 年度 × 数据场景 × 指标
```

唯一键：`region_id + data_year + metric_id + scenario`。

## 2. 公共维度

### 2.1 时间与数据场景

| 维度 | 当前值 | 用途 |
|---|---|---|
| 年度 | 2024、2025、2026 | 年度切换与趋势 |
| 场景 | `actual`、`test_5pct` | 实际/模拟隔离 |
| 是否模拟 | `0/1` | 页面明显标识模拟数据 |
| 基准年份 | 2024 或前一年 | 模拟追溯 |
| 数据截止日 | 2024-11-22 | 来源说明 |

### 2.2 空间维度

| 层级 | 数量 | 内容 |
|---|---:|---|
| 省级 | 1 | 福建省 |
| 地市级 | 9 | 福州、厦门、莆田、三明、泉州、漳州、南平、龙岩、宁德 |
| 特殊地市级 | 1 | 平潭综合试验区 |
| 源明细单元 | 101 | 标准区县、开发区、功能区、平潭片区 |
| 地图标准区县 | 83 | GPKG 县级调查界线 |

空间属性：`region_id`、名称、层级、父级、单元类型、规范地市、原始地市名称、原始区县名称、行政边界。

开发区、功能区、片区数据独立参与统计，不归并到标准区县。没有独立 GPKG 边界的 19 个源数据单元，以公开资料核定的近似中心经纬度在地图上显示为小圆点；点位仅用于业务数据展示，不代表行政边界或法定驻地。

### 2.3 房屋属性维度

- 建成年代：未知、60 年代及以前、70 年代、80 年代、90 年代、2000 年代、2010 年代及以后。
- 房屋结构：未知、钢结构、框架结构、砖混结构、底部框架-上部砖混结构、石结构、木（竹）结构、土木石木结构、砌体结构、混杂结构、钢筋混凝土结构、窑洞、其他。
- 城乡属性：城镇房屋、农村房屋。
- 建设/改造属性：2000 年及以前、2001 年至今、曾改造、拆改主体结构。

### 2.4 重点场所类型

统一枚举：

1. 经营性自建房
2. 人员密集场所
3. 九小场所
4. 多业态混合经营场所
5. 大跨度建筑
6. 历史建筑
7. 其他

### 2.5 隐患与整治维度

- 隐患等级：暂无安全隐患、一般安全隐患、重大安全隐患。
- 整治状态：已整治、整治中、未整治。
- 已整治方式：封房、加固、拆除、其他。
- 模型关系：`场所类型 × 隐患等级 × 整治状态 × 整治方式`。

## 3. 三大事实主题

### 3.1 房屋基础与排查事实：49 个指标

| 分类 | 指标数 | 属性 |
|---|---:|---|
| 排查结论 | 3 | 重大、一般、暂无隐患 |
| 建成年代 | 7 | 未知至 2010 年代及以后 |
| 房屋结构 | 13 | 13 类建筑结构 |
| 排查情况 | 8 | 排查总数、6 类重点场所、其他 |
| 经营性自建房 | 3 | 无/一般/重大隐患 |
| 人员密集场所 | 3 | 无/一般/重大隐患 |
| 九小场所 | 3 | 无/一般/重大隐患 |
| 多业态混合经营场所 | 3 | 无/一般/重大隐患 |
| 大跨度建筑 | 3 | 无/一般/重大隐患 |
| 历史建筑 | 3 | 无/一般/重大隐患 |

平台用途：房屋总览、隐患地图、建成年代结构、房屋结构、重点场所分布、区域排名。

### 3.2 安全隐患整治事实：72 个指标

六类重点场所分别包含 12 个指标：

```text
一般安全隐患
├── 已整治：封房、加固、拆除、其他
├── 整治中
└── 未整治

重大安全隐患
├── 已整治：封房、加固、拆除、其他
├── 整治中
└── 未整治
```

适用场所：经营性自建房、人员密集场所、九小场所、多业态混合经营场所、大跨度建筑、历史建筑。

平台用途：整治进度、重大隐患闭环、未整治清单统计、整治方式构成、场所类型对比、年度变化。

### 3.3 暂无隐患建筑潜在风险事实：59 个指标

| 分类 | 指标数 | 属性 |
|---|---:|---|
| 经营性自建房 | 7 | 总数、年代、人流密集、九小场所组合 |
| 历史建筑 | 14 | 总数及 13 类结构 |
| 老旧宅基地房屋 | 2 | 城镇、农村 |
| 1974 年前房屋 | 13 | 13 类结构 |
| 1975—1984 年房屋 | 2 | 木竹、砌体 |
| 1985—1994 年房屋 | 2 | 木竹、砌体 |
| 建成后曾改造房屋 | 11 | 总数、老旧房、主体结构及 8 类改造内容 |
| 结构变形损伤房屋 | 8 | 总数、老旧房、墙体/梁柱/地基/屋面/楼板/其他 |

改造内容枚举：加层、建筑外扩、拆改主体承重结构、加隔墙、开挖地下空间、加夹层、减柱、其他。

损伤部位枚举：墙体、梁柱、地基、屋面、楼板、其他。

平台用途：潜在风险专题、老旧房屋风险、改造行为分析、结构损伤分析、风险预警地图。

## 4. 指标编码体系

原始指标使用稳定编码：

| 前缀 | 主题 | 示例 |
|---|---|---|
| `basic` | 基础信息 | `basic.c003` 重大安全隐患 |
| `rectification` | 隐患整治 | `rectification.c014` 经营性自建房重大隐患未整治 |
| `potential_risk` | 潜在风险 | `potential_risk.c057` 结构损伤部位-梁柱 |

每个指标保存：指标编码、原工作表、原列号、显示名称、完整分类路径、主题、一级分类、单位、数值类型和聚合规则。

前端不可依赖 Excel 列序号硬编码，应通过 `metric_id` 或业务别名查询。

## 5. 建议增加的业务指标别名

在原始 180 个指标之上建立稳定业务指标层：

| 业务指标 | 计算口径 |
|---|---|
| 排查总数 | `basic.c026` |
| 隐患总数 | 一般隐患 + 重大隐患 |
| 综合隐患率 | 隐患总数 /（无隐患 + 一般 + 重大） |
| 重大隐患率 | 重大隐患 / 排查结论总数 |
| 已整治总数 | 各场所、各等级下四种已整治方式之和 |
| 整治中总数 | 各场所、各等级“整治中”之和 |
| 未整治总数 | 各场所、各等级“未整治”之和 |
| 整治率 | 已整治 /（已整治 + 整治中 + 未整治） |
| 重大隐患闭环率 | 重大隐患已整治 / 重大隐患整治状态总数 |
| 老旧房屋数量 | 2000 年及以前相关口径 |
| 改造房屋风险数 | 曾改造且涉及主体结构/重点改造内容 |
| 结构损伤风险数 | 结构变形损伤房屋总数 |
| 年度同比 | 本年值 / 上年值 - 1 |

所有比率必须在查询层由明确分子、分母计算，不能直接对各区县比率求和。

{
  "year": 2024,
  "scenario": "actual",
  "regionId": "350000",
  "regionLevel": "province",
  "topic": "overview",
  "metricId": "basic.c003",

## 8. 建议的平台功能模块

1. 综合态势：总量、隐患率、地图、地市排名、年度趋势。
2. 房屋画像：年代、结构、城乡属性、区域分布。
3. 隐患监测：一般/重大隐患、重点场所交叉分析。
4. 整治闭环：已整治、整治中、未整治及整治方式。
5. 重点场所：六类重点场所专题切换。
6. 潜在风险：老旧、改造、结构损伤、历史建筑。
7. 动态监测：2024 实际与 2025/2026 模拟趋势、同比和异常提示。
8. 数据质量：数据来源、汇总差异、模拟标识、行政区匹配状态。

## 9. 数据关联注意事项

- 101 个源明细单元与 83 个地图标准区县不是一一对应；标准区县使用面边界，区县外的 19 个开发区、功能区和片区使用独立点位，禁止归并后重复统计。
- “平潭综合实验区/平潭综合试验区”已在数据库中统一，源别名仍保留。
- “钢筋混凝士结构”已统一展示为“钢筋混凝土结构”，源行快照保留原文。
- 2024 地市汇总值与明细合计存在部分差异，平台默认展示源汇总值，并在数据质量模块提示。
- 2025/2026 仅用于功能测试，必须始终显示“模拟数据”标识。
