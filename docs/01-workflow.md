# 项目 workflow

## 1. 资料冻结与盘点

1. 原始 Excel、PDF 进入 `data/raw/`，只读保留，不在原文件上修改。
2. 记录来源、统计截止时间、工作表、行列规模和口径。
3. 取得福建省地市/区县行政区划代码与 GeoJSON 边界，放入 `data/reference/`。

交付：数据源清单、版本号、文件校验值。

## 2. 数据治理与标准化

1. 将 Excel 多行合并表头展开为稳定字段名。
2. 区分省级合计、地市级合计、区县/开发区/片区明细。
3. 建立行政区名称别名表，统一“平潭综合试验区/平潭综合实验区”等写法。
4. 为每条记录补齐 `region_code`、`region_level`、`parent_code`、`stat_date`、`data_year`。
5. 将宽表转为“区域 + 年份 + 指标 + 数值”的长表，同时保留可追溯的源字段。

质量门槛：关键字段非空；计数非负整数；区县能映射到唯一父级；汇总值与明细差异可解释。

## 3. 2024 基准数据入库

1. 导入区域维表、指标维表、数据源表。
2. 导入房屋基础、安全隐患整治、暂无安全隐患建筑三类事实数据。
3. 生成省、市、县级聚合视图。
4. 保存导入批次、来源文件、源工作表和源行号。

## 4. 2025/2026 模拟数据

建议采用“可复现的受约束随机浮动”，不是简单给整行乘同一系数：

1. 2025 以 2024 为基准，每个区县、每个可加总指标生成 `[-5%, +5%]` 浮动。
2. 2026 以 2025 为基准再生成 `[-5%, +5%]` 浮动。
3. 使用固定随机种子，保证每次生成结果一致。
4. 计数四舍五入为非负整数；比例限制在 `[0, 1]`。
5. 地市和全省数据由区县重新汇总，不对汇总行独立随机，避免上下级不一致。
6. 分类子项受父项约束；整治状态总数不得超过对应隐患数。
7. 所有模拟记录写入 `scenario='test_5pct'`、`is_simulated=true` 和基准年份。

## 5. 服务与动态监测

提供以下查询能力：

- 指定年度、区域、指标的地图分级设色数据
- 全省/地市/区县关键指标卡
- 地市横向排名和区县 Top N
- 2024—2026 年度趋势
- 隐患类型、房屋结构、建成年代、整治状态分布
- 同比变化、异常波动、未整治风险提示

## 6. 可视化大屏

首屏采用“中间地图 + 左右辅助图表 + 顶部指标卡 + 底部时间轴”。默认显示全福建省地市级；点击地市或缩放达到阈值后加载区县边界和数据；缩小后回到地市级。

所有图表共用当前筛选状态：年度、行政区、指标、场所类型、风险等级。地图悬浮显示核心指标，点击后刷新两侧图表。

## 7. 验证与验收

- 数据：总量勾稽、上下级汇总、空值、负数、重复键、模拟标识检查。
- 地图：行政区匹配率 100%，钻取与回退路径一致。
- 功能：年度切换后所有组件同步更新，无混用真实/模拟数据。
- 性能：省级首屏和地图层级切换达到约定响应目标。
- 安全：生产环境默认隐藏模拟场景，原始资料不直接暴露给前端。
