# 数据盘点与质量清单

## 数据源

### 系统导出表

- 文件：`data/raw/2024/housing-safety-export-2024-11-23.xlsx`
- 截止时间：2024-11-22（来自白皮书数据来源说明）
- 工作表：
  - `基础信息`：114 行、51 列；2 行复合表头
  - `安全隐患整治情况`：116 行、74 列；4 行复合表头
  - `暂无安全隐患建筑`：115 行、61 列；3 行复合表头
- 空间层级：全省总计、10 个地市级汇总单元、101 个区县/开发区/片区明细单元

### 2024 年白皮书

- 文件：`data/raw/2024/fujian-housing-safety-white-paper-2024.pdf`
- 168 页
- 主要内容：房屋总量与年龄、结构、安全隐患及空间分布、整治情况、风险识别、附表
- 作用：指标口径和图表需求参考；数据库数值以系统导出表为主。

## 可直接支持的主题

- 排查结论：重大、一般、暂无安全隐患
- 建成年代：60 年代及以前至 2010 年代及以后、未知
- 房屋结构：钢结构、框架、砖混、石、木竹、砌体、混杂等
- 重点类型：经营性自建房、人员密集场所、九小场所、多业态混合、大跨度、历史建筑
- 排查情况：重点类型和其他类型数量
- 整治情况：一般/重大隐患，已整治方式、整治中、未整治
- 潜在风险：老旧房屋、改造房屋、结构变形损伤等

## 已识别的数据治理问题

1. `平潭综合试验区` 与 `平潭综合实验区` 并存，需要名称别名映射。
2. 明细包含经济开发区和片区，并非全部是标准民政区县；地图展示需确定其空间边界或归并规则。
3. Excel 为多行合并表头，必须展开为唯一字段编码，不能直接以显示名称建库。
4. `钢筋混凝士结构` 疑似“钢筋混凝土结构”的文本错误，需统一展示名并保留源值。
5. 不同工作表表头起始行不同，导入规则必须按工作表配置。
6. 地市合计和全省合计已经存在；数据库应选择“保存源汇总 + 查询时重算核对”，避免重复统计。
7. 白皮书说明房屋总数约 912.59 万栋，而导出表不同主题的统计范围可能不同，不能将不同主题的“总数”直接混为同一口径。
