# 可视化大屏信息架构

## 首屏布局

- 顶部：平台标题、数据时间、年度切换、全屏、数据状态（实际/模拟）。
- 顶部指标卡：房屋总量、一般隐患、重大隐患、隐患率、已整治、整治率。
- 中央：福建省地图，占主视觉约 50%。
- 左侧：地市隐患数量排名、房屋建成年代结构、2024—2026 趋势。
- 右侧：隐患等级分布、重点场所类型、整治状态/整治方式。
- 底部：年度时间轴、当前筛选条件、数据来源说明。

## 地图交互

1. 初始为福建省地市级分级设色。
2. 悬浮：区域名、排查总数、重大/一般隐患、隐患率、同比。
3. 点击地市：聚焦并切换区县级边界；两侧图表同步过滤。
4. 缩放达到阈值：自动切换区县层；回缩后恢复地市层。
5. 面包屑：福建省 / 当前地市，支持一键回到全省。
6. 对没有独立边界的开发区/片区，按确认后的归并规则展示，避免无图形数据点。

## 动态监测

- 年度：2024 实际、2025 模拟、2026 模拟。
- 趋势：展示年度值和同比，模拟年份使用明显的虚线/标签。
- 告警：重大隐患上升、未整治数量上升、整治率下降时触发颜色提示。
- 联动：任何区域或指标选择均更新地图、卡片、柱状图和折线图。

## 对标厦漳泉都市圈平台时需重点确认

- 视觉风格、配色、字体、背景、动效节奏
- 顶部导航和专题切换方式
- 地图底图、行政边界、下钻与返回交互
- 图表密度、信息层级和大屏分辨率
- 是否需要轮播、自动巡检、事件弹窗和多屏适配
